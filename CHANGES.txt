.. towncrier release notes start

1.2 (2026-11-21)
================

* Changed the servers to listen on ``localhost`` by default, instead of on all network
  interfaces. Added a ``-b/--bind`` option (``AIO_BIND_ADDRESS`` env variable) to
  ``runserver`` and ``serve`` to listen on another address, e.g. ``--bind 0.0.0.0``
  for the previous behaviour.
* Added HTTPS support to ``runserver``. ``--ssl-context-factory`` names a function in the
  app's module which returns the ``ssl.SSLContext`` to serve with, and ``--ssl-rootcert``
  gives the root certificate to trust when a self-signed certificate is used.
* Added support for Python 3.12, 3.13, 3.14 and 3.15, and dropped support for Python 3.8,
  3.9 and 3.10.
* Enabled asyncio's debug mode when running the app, which reports problems such as code
  blocking the event loop.
* Updated ``livereload.js`` from v2.2.1 to v4.0.3. It is now served with an ``ETag``, so
  that browsers don't keep using a copy cached from a previous version.
* Fixed a 500 error when a static file which doesn't exist is requested with aiohttp 3.10+.
* Fixed the file watcher crashing when a file other than a ``.py`` file changed while
  ``--static`` was not used, after which nothing was reloaded or restarted.
* Fixed live reload not working when ``adev serve`` is given a relative path, or serves on
  port 80 or 443.
* Fixed a change to a static file prompting two reloads when the static directory is inside
  the project.
* Fixed the app being imported from the wrong place when a module with the same name comes
  earlier in ``sys.path``.
* Fixed connections being reset while the dev server is starting.
* Fixed the name of the env variable in the help for ``--static`` (``AIO_STATIC_PATH``).

1.1.2 (2023-12-07)
==================

* Improved reliability of reloads by delaying multiple reloads until the browser has
  reconnected, and increasing the period of time to gather filesystem changes.

1.1.1 (2023-11-19)
==================

* Use ``aiohttp.web.AppKey`` to avoid warnings on aiohttp 3.9.

1.1 (2023-06-30)
================

* Display a list of available files in the static handler when serving a 404 error.
* Add ``no-cache`` headers to disable browser caching (can be disabled with ``--browser-cache``).
* Improved reliability of live reload by waiting up to 15 seconds (previously 2) for the app to restart and allowing the browser to reconnect when multiple files change quickly.
* Fixed unclean shutdowns on Windows by introducing a shutdown by endpoint method (Windows doesn't work with the default signals method).
* Changed to run with ``asyncio.Runner`` on Python 3.11+ (apparently fixing an issue with reloads on Windows).
* Rewrote the package name dynamically to match the app's name (e.g. used in aiohttp-admin as a default admin title).
* Migrated from ``watchdog`` dependency to the newer ``watchfiles``.

1.0.post0 (2021-12-31)

1.0 (2021-12-31)
================

* Add support for passing arguments to the application, like ``adev runserver [adev-args] project -- [project-args]``
* Remove ``start`` command (take a look at create-aio-app for an alternative).
* Remove debugtoolbar integration (it must be installed manually now).
* Fix an error when reloading a file not in the static path.
* Fix app cleanup not running is some situations.
* Fix static URLs in subapps.
* Fix support for aiohttp 3.8+.
